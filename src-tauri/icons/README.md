# アイコンについて

このディレクトリには、アプリケーションのアイコンファイルを配置します。

## 必要なアイコンファイル

Tauriでビルドする際には、以下のアイコンファイルが必要です:

- `32x32.png` - 32x32ピクセル
- `128x128.png` - 128x128ピクセル
- `128x128@2x.png` - 256x256ピクセル (Retina対応)
- `icon.icns` - macOS用アイコン
- `icon.ico` - Windows用アイコン

## アイコン生成方法

1つのPNG画像から、Tauri CLIで自動生成できます:

```bash
npm install -g @tauri-apps/cli
tauri icon path/to/your-icon.png
```

上記コマンドで、必要なすべてのサイズのアイコンが自動生成されます。

## 元画像の推奨サイズ

- 最低: 512x512ピクセル
- 推奨: 1024x1024ピクセル
- フォーマット: PNG (透過背景推奨)

## 注意

アイコンファイルがない場合でも開発は可能ですが、ビルド時にはアイコンが必要になります。
デフォルトのTauriアイコンを使用する場合は、Tauriプロジェクト生成時のアイコンをコピーしてください。
